# JP Reiss Environmental Group — Website (Option C)

Static, self-contained HTML/CSS/JS site designed for **JP Reiss Environmental Group** (`josephreissjr.com`) and ready for deployment via **GitHub Pages**.

## Included Files
- `index.html` — Complete single-page layout with sections for Services, Sampling Methodologies, 10-Step Client Journey, About Joe & Credentials, Research & Podcasts, Consulting/Resources, and Assessment Intake Form.
- `styles.css` — Responsive stylesheet using a warm homeowner-first editorial palette.
- `script.js` — Interactive modals (prepaid consultation, sampling/payment policy, consulting sign-up) and structured form payload handoff for monday.com integration.

## Publishing to GitHub Pages
1. Create a new repository on GitHub (or push to an existing repository).
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the root of the `main` branch.
3. Open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, and click **Save**.
